# 🔤 Word-solver

A fast, client-side word unscrambler tool that finds every valid word from any set of letters. Built with vanilla HTML, CSS, and JavaScript — **no server required**.

🔗 **Live Demo:** `https://yourusername.github.io/word-unscrambler`

---

## ✨ Features

- 🚀 **Instant results** — type letters and hit Enter
- 📚 **370,000+ word dictionary** — loads from CDN
- 🎯 **Length filters** — set min/max word length
- 📱 **Fully responsive** — works on mobile, tablet, desktop
- ⚡ **100% client-side** — no data sent to any server
- 🎨 **Clean, modern UI** — with loading spinner and smooth animations

---

## 🛠️ How to Use

1. Enter any letters (e.g., `cbiinr`)
2. Set minimum and maximum word length (default: 3–7)
3. Click **"Unscramble"** or press **Enter**
4. All valid words appear instantly, sorted by length

---

## 🧰 Tech Stack

- HTML5
- CSS3 (flexbox, gradients, backdrop blur)
- Vanilla JavaScript (ES6)
- [word-list](https://www.npmjs.com/package/word-list) dictionary via CDN

---

## 🚀 Deployment

This site is static and can be deployed anywhere:

- **Netlify** — drag and drop `index.html`
- **GitHub Pages** — push to a repo and enable Pages
- **Vercel** — one-click deployment
- **Any web host** — just upload the single HTML file
